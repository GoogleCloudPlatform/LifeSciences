# Phase 3 Batch B — json, pockets, sdf viewer ports (#154)

**Date:** 2026-08-20
**Branch:** `scion/vr-p3`
**Issue:** #154 (viewer reconciliation)

## Summary

Ported domain-specific features into three viewers: `json-viewer.html`,
`pockets-viewer.html`, and `sdf-viewer.html`, following the port-into-shipped
pattern. These are minor viewers with targeted improvements.

## Changes

### json-viewer.html

Ported from original prototype:
- **Interactive collapsible tree view** — recursive DOM builder renders JSON as a
  tree with clickable toggle arrows to expand/collapse objects and arrays
- **Type-colored values** — strings, numbers, booleans, and null each get distinct
  colors (blue, green, red, gray italic)
- **Item counts** — collapsed containers show key/item counts (e.g., "5 keys",
  "12 items")
- **Copy-to-clipboard button** — copies formatted JSON string with "Copied!"
  feedback
- **Formatted/Tree View toggle** — two buttons switch between syntax-highlighted
  raw view and interactive tree view; defaults to Formatted (raw) view

Preserved from shipped:
- `?file=` URL scheme (no `/raw/` prefix)
- Graceful JSON parse failure (falls back to raw text display; disables tree
  button when JSON is invalid)
- highlight.js syntax highlighting for raw view (pinned to `@11.12.0`)
- `showError` function and error div

### pockets-viewer.html

Ported from original prototype:
- **Sortable table columns** — clickable headers with sort arrows; columns: Rank,
  Score, Druggability, Volume, Total SASA, Alpha Spheres, Polar SASA %
- **Score/druggability color badges** — green (> 0.5), amber (>= 0.3), red (< 0.3)
- **Numeric formatting** — score and druggability to 3 decimals, volume and total
  SASA to 1 decimal, alpha spheres as integer, polar SASA as percentage
- **Top-pocket row highlighting** — rank-1 row gets distinct blue background
- **Computed polar SASA proportion** — calculates `polar_sasa / total_sasa` when
  the proportion is not directly available in data
- **Info bar** — pocket count, top score, and top druggability summary

Preserved from shipped:
- `?file=` URL scheme (no `/raw/` prefix)
- Empty-data validation ("No pockets found")
- Single-object wrapping (`Array.isArray(data) ? data : (data.pockets || [data])`)
- `showError` function and error div

### sdf-viewer.html

Ported from original prototype:
- **Style selector** — 4 styles: Ball & Stick, Stick, Sphere, Line (shipped only
  had stick)
- **SDF property parsing** — parses `> <NAME>` property blocks from SDF text into
  a sidebar property table
- **Molecule name extraction** — reads the first line of the SDF file as the
  molecule name; falls back to filename if empty
- **Sidebar panel** — shows molecule name and parsed properties next to the 3D
  viewer; hides when no properties or name available

Removed from shipped:
- **Permanent atom property labels** — every-atom labeling cluttered the view;
  replaced with hover-only labels showing element and atom index

Preserved from shipped:
- `?file=` URL scheme (no `/raw/` prefix)
- `3Dmol@2.4.2` (pinned CDN)
- `showError` function and error div
- Hover labels (element + atom index on hover)

Skipped (per spec):
- Header chrome, file metadata, default fallback files
