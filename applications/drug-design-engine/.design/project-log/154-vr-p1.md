### structure-viewer.html Port

Ported from the original prototype into the shipped viewer's structure:

- **pLDDT confidence coloring** as default color mode with AlphaFold-standard 4-band colors (`#0053D6`, `#65CBF3`, `#FFDB13`, `#FF7D45`)
- **Color mode selector** dropdown: pLDDT / By Chain / Uniform
- **pLDDT sidecar loading**: fetches `.plddt.json` alongside `.cif`; handles both `residue_plddt` object and flat array formats
- **B-factor heuristic**: detects pLDDT-in-B-factor (mean B between 20 and 100) and skips sidecar override
- **Chain coloring**: D3 category10 palette (10 colors)
- **Ligand styling**: hetflag atoms always rendered as ball-and-stick
- **pLDDT legend bar**: conditionally visible only in pLDDT color mode

Preserved from shipped viewer:
- `?file=` URL scheme (no `/raw/` prefix)
- `showError` function and error div
- Spin toggle button

Skipped from original (per spec):
- Header chrome / back link
- Line style option
- Default fallback file
- `/raw/` base path prefix
