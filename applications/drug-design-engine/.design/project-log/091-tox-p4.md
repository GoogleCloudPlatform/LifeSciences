# Phase 4: `tox margins` — cross-artifact TI and hERG margin

**Agent:** tox-dev-p4
**Date:** 2026-08-19
**Branch:** `scion/tox-p4`
**Issue:** #91

## What was done

Implemented `tox margins` subcommand in `tools/venter/commands/tox.py`.
This is Phase 4 of the tox tool build — the cross-artifact read and
margin computation.

### Deliverables

1. **`tox margins TOX_FILE PK_FILE [--herg FILE]`** subcommand added to
   the `tox` Click group.

2. **Therapeutic index calculation** from NOAEL exposure vs PK NCA
   exposure:
   - TI_cmax = noael_cmax / pk_cmax (when both available)
   - TI_auc = noael_auc / pk_auc (when both available)
   - Graceful decline when `noael_exposure` absent — `margins: null`
     with `margin_note` explaining why TI cannot be computed.

3. **hERG safety margin** via `--herg` flag: reads a
   `venter.tox-safety-pharm.v1` artifact, computes IC50 / pk_cmax.

4. **Unit mismatch enforcement**: string comparison of units between tox
   and PK artifacts; raises `Refusal` on mismatch (no unit conversion
   by design).

5. **Cross-artifact provenance**: PK source file and SHA-256 recorded in
   sidecar. Upstream PK sidecar `mandatory_relays` forwarded into the
   margins sidecar via `sidecar.warn(message, code=code)`.

6. **Output structure** matches the design doc spec:
   - `{study_id}.tox-margins.json` (artifact)
   - `{study_id}.tox-margins.meta.json` (sidecar)
   - Schema: `venter.tox-margins.v1`

### Design decisions

- Used `auc_0_inf` from PK NCA with fallback to `auc_0_t` when infinity
  extrapolation is unavailable.
- `margin_calculation_method` field included in artifact only when
  margins are actually computed (matches spec for absent case).
- PK sidecar relay forwarding reads `.pk-nca.meta.json` beside the PK
  file and carries all mandatory relays through.
