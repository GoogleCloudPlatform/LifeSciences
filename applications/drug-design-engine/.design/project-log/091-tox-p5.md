## What was built

### 1. Threshold set: `tox-safety-package@1.0`

Added to `tools/venter/core/thresholds.py` with four values:

- `ti_minimum: 10.0` — ICH M3(R2) therapeutic index convention
- `herg_safety_margin: 30.0` — ICH S7B, ≥30-fold between therapeutic Cmax and hERG IC50
- `herg_marginal: 10.0` — operational boundary (herg_safety_margin / 3), selectivity-margins precedent
- `noael_exposure_margin: UNRESOLVED` — program-specific, no universal default

Declared independently from `selectivity-margins` per design doc OQ1 to avoid cross-tool coupling.

### 2. `_SCHEMA_MAP` dispatch table

Three entries mapping phase-1 artifact schemas to analysis types:

- `venter.tox-margins.v1` → `"margins"`
- `venter.tox-genotox-assessment.v1` → `"genotox"`
- `venter.tox-safety-pharm.v1` → `"safety-pharm"`

`tox-repeat-dose.v1` is correctly excluded — repeat-dose is analysed through `margins`, not directly.

### 3. Analysis helpers

- **`_analyze_margins`**: Compares TI (Cmax and AUC) against `ti_minimum` threshold. Handles missing NOAEL exposure (verdict: `"incomplete"`). Compares hERG safety margin against both `herg_safety_margin` and `herg_marginal` thresholds when hERG data is present.
- **`_analyze_genotox`**: Categorical verdict mapping — `negative` → `"acceptable"`, `equivocal` → `"flagged_equivocal"`, `concern`/`positive_concern`/`positive` → `"flagged_concern"`. No threshold application needed.
- **`_analyze_safety_pharm`**: Records hERG IC50 as metric, summarises cardiovascular/respiratory/CNS fields if present. Verdict: `"recorded"` — quantitative margin lives in `tox margins`.

### 4. `analyze_cmd`

Phase 2 subcommand following the PK `analyze_cmd` pattern exactly:
- Resolves input artifact, dispatches on schema via `_SCHEMA_MAP`
- Loads `tox-safety-package` thresholds
- Collects upstream relays from phase-1 sidecar
- Dispatches to analysis helper
- Writes via `provenance.write_analysis()`
- Bounded summary output (verdict, threshold set, unresolved thresholds)

## Design decisions

1. **Followed PK analyze_cmd pattern verbatim** — same structure for resolve → dispatch → threshold load → relay collect → helper → write → emit.
2. **No new relay codes** — the only relay code is `tox.genotox_weight_of_evidence` (already registered in Phase 3).
3. **`noael_exposure_margin` never called via `thresholds.get()`** — it is UNRESOLVED and would raise `ThresholdError`. The analysis helpers use only `ti_minimum`, `herg_safety_margin`, and `herg_marginal`.

## Deviations from spec

None. Implementation matches the brief and design doc exactly.
