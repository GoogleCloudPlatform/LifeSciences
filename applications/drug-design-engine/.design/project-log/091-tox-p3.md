## What was done

Phase 3 of the tox tool: implemented the `tox genotox` subcommand for
ICH S2(R1) weight-of-evidence assessment of a genotoxicity battery.

### Deliverables

1. **Relay code registered:** `tox.genotox_weight_of_evidence` added to
   `RELAY_CODES` in `provenance.py` with obligation phrasing per the
   design doc.

2. **`_classify_genotox_battery()` scoring function:** Implemented in
   `tox.py` exactly as specified. Returns `(verdict, weight_of_evidence_needed)`
   covering all 5 outcome categories:
   - `negative` (all negative, no WoE)
   - `positive` (all positive, no WoE)
   - `equivocal` (in vitro positive only, WoE needed)
   - `concern` (in vivo positive, WoE needed)
   - `positive_concern` (2+ positives, WoE needed)

3. **`tox genotox` subcommand:** Reads `.tox-genotox.json` from ingest,
   classifies the battery, builds descriptive `weight_of_evidence_basis`
   text with ICH S2(R1) reference, and writes:
   - `{compound_id}.tox-genotox-assessment.json` (assessment artifact)
   - `{compound_id}.tox-genotox-assessment.meta.json` (provenance sidecar)

4. **Relay fires conditionally:** `tox.genotox_weight_of_evidence` fires
   only on mixed battery results (weight_of_evidence_needed == True).
   All-negative and all-positive batteries emit no relay.

### Files modified

- `tools/venter/core/provenance.py` — added relay code
- `tools/venter/commands/tox.py` — added `_classify_genotox_battery()`,
  `_build_weight_of_evidence_basis()`, and `genotox_cmd`
