# Phase 2 Batch B — docking, docking-scores, admet viewer ports (#154)

**Date:** 2026-08-20
**Branch:** `scion/vr-p2`
**Issue:** #154 (viewer reconciliation)

## Summary

Ported domain-specific features into three viewers: `docking-viewer.html`,
`docking-scores-viewer.html`, and `admet-viewer.html`, following the
port-into-shipped pattern established in Phase 1.

## Changes

### docking-viewer.html

Ported from original prototype:
- **PDBQT MODEL block parsing** — splits poses text into individual MODEL blocks
  using `MODEL`/`ENDMDL` markers; falls back to single model if no markers found
- **Pose-by-pose navigation** — Prev/Next buttons cycle through poses; shows only
  the current pose model, hides all others
- **Docking score extraction** — parses `REMARK VINA RESULT` lines from PDBQT and
  displays kcal/mol score for the current pose
- **Pocket residue highlighting** — computes receptor residues within 5Å of the
  best pose (pose 0); toggle button shows/hides as orange sticks
- **Receptor style toggle** — Cartoon / Surface dropdown for the receptor model
- **Auto-discovery** — when loaded with `?file=`, tries to fetch the paired
  file by naming convention (e.g., `X.poses.pdbqt` → `X.receptor.pdbqt`);
  silently falls back to single-file mode on failure

Preserved from shipped:
- `?file=` URL scheme with extension detection (`.receptor.pdbqt` / `.poses.pdbqt`)
- Single-file mode (receptor-only or poses-only rendering)
- `showError` function and error div

### docking-scores-viewer.html

Ported from original prototype:
- **Score banding colors** — semantic green (`#16a34a`, < -8.0), blue (`#3b82f6`,
  -8.0 to -6.0), gray (`#94a3b8`, > -6.0) replacing the gradient color scheme
- **Threshold reference lines** — horizontal dashed lines at -8.0 and -6.0
  kcal/mol with "Strong" and "Moderate" text annotations
- **Score text labels** — kcal/mol values displayed above each bar

Preserved from shipped:
- `?file=` URL scheme (single-file mode)
- RMSD scatter overlay on secondary axis
- Multi-format data detection (array, poses/results/modes wrappers)
- Error handling pattern
- HTML score band legend added below chart

### admet-viewer.html

Ported from original prototype:
- **Domain-specific ADMET endpoints** — 5 standard endpoints with human labels
  (Metabolic Stability, CYP Inhibition, Permeability, hERG Liability, Solubility)
- **3-level scoring thresholds** — acceptable (3, green), marginal (2, amber),
  unacceptable (1, red) mapping
- **Verdict badges** — passed/flagged/failed assessment displayed as styled badges
  with semantic background colors
- **Per-endpoint semantic coloring** — radar chart markers colored by endpoint
  acceptability level
- **ADMET format detection** — checks for `metrics.endpoint_results` to route to
  domain-specific rendering

Preserved from shipped:
- `?file=` URL scheme (single-file mode)
- Multiple data format support (array, wrapper, plain object) as generic fallback
- Bar chart fallback for <3 properties
- Error handling pattern

Skipped (deferred per spec):
- Multi-file compound comparison (`?files=`)
- Ligand efficiency computation (docking-scores)
- SMILES-to-name mapping (admet)
