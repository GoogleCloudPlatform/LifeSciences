# Project Log: `venter mmp` — Matched Molecular Pair Analysis (Issue #51)

**Date:** 2026-08-19
**Author:** tools-lead-em-51-dev-mmp
**Scope:** `tools/venter/commands/mmp.py`, `tools/venter/core/provenance.py`, `tools/venter/core/thresholds.py`, `tools/venter/cli.py`

## Summary

Implemented the `venter mmp` command group with three subcommands for matched molecular pair (MMP) analysis using RDKit BRICS decomposition. MMP analysis identifies pairs of molecules that share the same scaffold but differ at a single R-group position, enabling structure-activity relationship (SAR) analysis.

## What was built

### `mmp fragment <SMILES>` — Phase 1

BRICS-decompose a SMILES string. Records:
- Full decomposition (all BRICS bonds cut simultaneously → fragment set)
- Every single-cut core/R-group pair (one BRICS bond cut at a time)
- RDKit version in provenance sidecar

All valid BRICS cuts are reported — the tool never silently picks one (§8 "never rank and pick"). Writes to `raw/compounds/`.

### `mmp pairs <series-file>` — Phase 1

Parse a `venter.mmp-series.v1` JSON file containing compounds with SMILES and measured properties. For each compound, fragment via BRICS single-cuts, then identify matched pairs: two compounds whose single-cut decomposition yields the same core but different R-groups. Property deltas are computed for each pair.

Schema validation: non-canonical-schema input raises `Refusal` (exit 9), matching the pattern from `assay.py` ingest.

### `mmp analyze <pairs-artifact>` — Phase 2

Reads the `.mmp-pairs.json` artifact from `pairs`, loads the `mmp-cliffs` threshold set, and applies property-cliff detection. A cliff is a transformation where the property delta exceeds the configured `cliff_absolute_delta` threshold.

Relays fired:
- `mmp.cliff_not_causation` — when any property cliff is detected. A property cliff is a correlation, not a causal mechanism.
- `mmp.small_pair_count` — when a transformation has fewer pairs than `min_pair_count`. Insufficient pairs cannot support a trend.

### Infrastructure changes

- **provenance.py**: Registered `mmp.cliff_not_causation` and `mmp.small_pair_count` relay codes
- **thresholds.py**: Declared `mmp-cliffs` threshold set (version 1.0): `min_pair_count=3` (resolved), `cliff_fold_change` and `cliff_absolute_delta` (UNRESOLVED — program-specific). Provenance cites Hussain & Rea, J Chem Inf Model 2010;50:339-348.
- **cli.py**: Imported and registered the `mmp` command group before `enforce_phase_two(cli)`

## Design decisions

1. **BRICS for fragmentation**: BRICS decomposition is deterministic for a given molecule and RDKit version (verified empirically across 5 runs). This makes the fragment and pairs subcommands reproducible.

2. **Single-cut approach for MMP identification**: Rather than using the full BRICS decomposition (all bonds cut), each molecule is cut at individual BRICS bonds. Two compounds are a matched pair when any single-cut yields the same core fragment but a different R-group. This is the standard BRICS-based MMP paradigm.

3. **UNRESOLVED cliff thresholds**: `cliff_fold_change` and `cliff_absolute_delta` have no universal defaults in the MMP literature. They are declared UNRESOLVED, requiring explicit program configuration. When UNRESOLVED, the analyze subcommand still runs (detecting low pair counts) but skips cliff detection with an advisory.
