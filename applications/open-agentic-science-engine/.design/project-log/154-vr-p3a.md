## Summary

Ported domain-specific scientific visualization features from original
prototypes into three shipped viewers: constraint-viewer, pae-viewer,
and expression-viewer. All three are Phase 3 "minor" viewers with
targeted improvements.

## Changes

### constraint-viewer.html

- **Three-tier classification** for 6 gnomAD metrics (pLI, LOEUF,
  oe_lof, oe_mis, lof_z, mis_z) with per-metric thresholds for
  constrained/borderline/tolerant
- **Nested data navigation** traversing `data.data.gene.gnomad_constraint`
  with fallbacks to `data.gene` and direct `data`
- **Gene header** showing gene symbol, full name, Ensembl ID, and
  chromosomal location
- **Metric cards** with large formatted values, labels, descriptions,
  threshold info, observed/expected counts, and confidence intervals
- **Clinical interpretation paragraph** based on pLI and LOEUF values,
  with missense constraint note when mis_z > 3.09
- Replaced shipped flat key-value dump with structured scientific display

### pae-viewer.html

- **AlphaFold-standard colorscale** — 12-step green-to-red replacing
  the shipped non-standard 3-step blue-green-red scale
- **Color normalization** using `max_predicted_aligned_error` (default
  31.75) for `zmin: 0, zmax: maxPAE`
- **Square aspect ratio** enforced with `scaleanchor: 'x'`
- **Proper hover template** showing scored residue, aligned residue,
  and PAE in Angstroms
- **Three data format support**: raw 2D array, AlphaFold DB wrapped
  `[{predicted_aligned_error, max_predicted_aligned_error}]`, and
  object wrapped `{predicted_aligned_error}`

### expression-viewer.html

- **HPA tissue-key parsing** via regex `/^Tissue RNA - (.+) \[nTPM\]$/`
  to extract tissue names from Human Protein Atlas format
- **Absolute threshold coloring**: red (#dc2626) > 10 nTPM, amber
  (#d97706) > 2 nTPM, blue (#3b82f6) <= 2 nTPM — biologically
  meaningful thresholds replacing the shipped relative gradient
- **Gene name extraction** from `Gene` or `gene` field in data
- **Sorted horizontal bar chart** with tissues sorted by expression
  value descending
- **Fallback to generic formats** (array of objects, plain object)
  when no HPA-format keys are found
