# Phase 2 Batch A — plddt-viewer + contacts-viewer port (#154)

**Date:** 2026-08-20
**Branch:** `scion/vr-p2`
**Issue:** #154 (viewer reconciliation)

## Summary

Ported domain-specific features into `plddt-viewer.html` and
`contacts-viewer.html` from the original prototypes. Both viewers had
correctness bugs where the shipped version could not render the project's
actual data formats.

## Changes

### plddt-viewer.html (correctness bug fix)

**Fixed:** The shipped viewer read only `plddt` and `confidenceScore` keys,
but AlphaFold outputs use `residue_plddt` and `atom_plddt`. The viewer
silently failed to render standard AlphaFold Database data.

Ported from original:
- **Data format key resolution** — 5-level priority: flat array,
  `residue_plddt` (AlphaFold standard), `atom_plddt`, `plddt` (fallback),
  `confidenceScore` (fallback)
- **Per-chain support** — when `residue_plddt` is an object with chain keys,
  each chain is plotted as a separate trace with offset X coordinates and
  D3 category10 palette colors
- **Chart type** — changed from bar chart to scatter/line chart (conventional
  pLDDT visualization)
- **Confidence band rectangles** — replaced dotted threshold lines at 50/70/90
  with semi-transparent colored rectangles matching AlphaFold standard
  (blue >90, cyan 70-90, yellow 50-70, orange <50)

Preserved from shipped:
- `?file=` URL scheme, `showError` function, `plddtColor` function, legend

Skipped: info bar, header chrome, default fallback file

### contacts-viewer.html (wrong data model fix)

**Fixed:** The shipped viewer implemented a symmetric residue-residue contact
matrix, but the project's data uses a docking contact format
(`{contacts: [{pose, residues: [{chain, res_name, res_num, min_distance}]}]}`).

Ported from original:
- **Docking contact data model** — parses compound-residue docking contacts
  with best-pose extraction (pose 1 or first available)
- **Compound name extraction** — derived from filename by stripping
  `.contacts.json` suffix
- **Chain-aware X-axis** — residues sorted by chain then res_num, with dashed
  chain divider line between chain groups
- **Green-to-blue colorscale** — 7-stop domain-standard distance colorscale
  (close = green, distant = blue)
- **Hover template** — shows compound name, residue, chain, distance in
  Angstroms
- **Inter-chain binding detection** — compounds contacting multiple chains
  are tagged

Preserved from shipped:
- `?file=` URL scheme, `showError` function, `contactListToMatrix()` fallback
  for generic contact data, all matrix format detection cases (bare 2D array,
  `{matrix}`, `{contacts}` non-docking, `{contact_list}`, bare contact objects,
  `{data}` wrapper)

Skipped: multi-file loading (`?files=`), hardcoded chain names, default file
list, header chrome
