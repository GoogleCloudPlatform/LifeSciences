# Deploy Argus Agent with Terraform

This directory contains the Terraform configuration to provision Google Cloud infrastructure for the **Argus — Life Sciences M&A Diligence** agent (`argus-on-gemini-enterprise`). It provisions the Agent Runtime (Reasoning Engine) instance on Gemini Enterprise Agent Platform, Google Cloud Storage buckets for logs and generated artifacts (whitepapers, charts, infographics), enables required APIs, and assigns the required IAM roles to the Agent Identity principal.

Agent code packaging and deployment to the provisioned Agent Runtime instance is automated via Cloud Build using the shared pipeline (`shared/cloudbuild.yaml`).

## Features

* **Agent Identity Integration:** Configures the Agent Runtime (Reasoning Engine) with `identity_type = "AGENT_IDENTITY"` and binds least-privilege IAM roles to the runtime principal (`principal://...`):
  * `roles/agentregistry.viewer`
  * `roles/aiplatform.expressUser`
  * `roles/browser`
  * `roles/serviceusage.serviceUsageConsumer`
  * `roles/telemetry.writer` (Cloud Observability tracing and telemetry)
  * `roles/storage.objectUser` on both the logs bucket and the artifacts bucket
* **Artifact Storage:** Manages a dedicated Google Cloud Storage bucket (`<project_id>-argus-artifacts` by default or custom `artifact_bucket_name`) for storing persistent whitepaper PDFs, charts, and infographics generated by the agent.
* **Logs Storage:** Manages a Google Cloud Storage bucket (`<project_id>-argus-agent-logs` by default or custom `logs_bucket_name`) for agent telemetry and execution logs.
* **API Enablement:** Enables necessary Google Cloud service APIs (`aiplatform.googleapis.com`, `agentregistry.googleapis.com`, `storage.googleapis.com`, `discoveryengine.googleapis.com`, `cloudresourcemanager.googleapis.com`).

## Prerequisites

1. **Terraform v1.0+** installed locally.
2. **Google Cloud Provider 7.28.0+** (`version = ">= 7.28.0"`).
3. Standard GCP APIs enabled in your target project (or permissions to enable them):
   * `aiplatform.googleapis.com` (Agent Platform / Agent Runtime)
   * `agentregistry.googleapis.com` (Agent Registry)
   * `discoveryengine.googleapis.com` (Gemini Enterprise / Discovery Engine)
   * `storage.googleapis.com` (Cloud Storage)
   * `cloudresourcemanager.googleapis.com` (Cloud Resource Manager)
   * `cloudbuild.googleapis.com` (Cloud Build for CI/CD deployments)
4. Suitable GCP credentials configured via:
   ```bash
   gcloud auth application-default login
   ```

## Configuration Variables

Configure these variables in a `terraform.tfvars` file or pass them via the command line (`-var`).

| Variable | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| **`project_id`** | `string` | **(Required)** The Google Cloud Project ID. | *None* |
| **`region`** | `string` | The GCP region to deploy the Agent Runtime to. | `"us-central1"` |
| **`logs_bucket_name`** | `string` | Existing GCS bucket to use for logs. If not provided, `<project_id>-argus-agent-logs` will be created. | `null` |
| **`artifact_bucket_name`** | `string` | Existing GCS bucket to use for artifacts (whitepapers). If not provided, `<project_id>-argus-artifacts` will be created. | `null` |

## Outputs

| Output | Description | Source |
| :--- | :--- | :--- |
| **`reasoning_engine_id`** | The full resource name of the deployed Agent Runtime (Reasoning Engine). | `module.agent_infra.reasoning_engine_id` |
| **`reasoning_engine_name`** | The generated ID of the Agent Runtime (Reasoning Engine). | `module.agent_infra.reasoning_engine_name` |
| **`agent_identity`** | The effective identity principal used at runtime. | `module.agent_infra.agent_identity` |
| **`agent_display_name`** | The display name of the Agent Runtime. | `module.agent_infra.agent_display_name` |
| **`agent_description`** | The description of the Agent Runtime. | `module.agent_infra.agent_description` |
| **`logs_data_bucket`** | The bucket name used for storing logs data. | `module.agent_infra.logs_data_bucket` |
| **`artifact_bucket`** | The bucket name used for storing artifact data (whitepapers). | `local.artifact_bucket_name` |

## Deployment Guide

### CI/CD Deployment via Cloud Build (Recommended)

In production, this Terraform configuration is automatically applied as part of the shared Cloud Build deployment pipeline (`shared/cloudbuild.yaml`).

Refer to the deployment instructions in the [Pharma on Gemini Enterprise Root README](../../README.md#cicd-deployment-service-account) or the [Argus README](../README.md#deploy-with-terraform--cloud-build-recommended-for-production).

#### Example Cloud Build Command:

```bash
# Run from applications/pharma-on-gemini-enterprise/argus-on-gemini-enterprise/
gcloud builds submit --config=../shared/cloudbuild.yaml \
    --substitutions=_TF_STATE_BUCKET="YOUR_STATE_BUCKET_NAME",_ENV_VARS="EDGAR_USER_AGENT=Sample Company Name AdminContact@<sample company domain>.com" \
    --project=YOUR_PROJECT_ID
```

### Local Development / Validation (Optional)

If you want to validate or plan the Terraform configuration locally before deploying:

1. **Initialize** (requires a GCS bucket for remote state):
   ```bash
   terraform init -backend-config="bucket=YOUR_TF_STATE_BUCKET" -backend-config="prefix=terraform/argus-agent"
   ```
2. **Validate**:
   ```bash
   terraform validate
   ```
3. **Plan**:
   ```bash
   terraform plan -var="project_id=YOUR_PROJECT_ID" -var="region=us-central1"
   ```
